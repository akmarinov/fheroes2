HEROES OF MIGHT AND MAGIC II

This is the fheroes2 engine compiled to WebAssembly. It reproduces the original game and needs its resource files to run: data/HEROES2.AGG for the base game, and additionally data/HEROES2X.AGG for The Price of Loyalty or the Restoration of Erathia expansion.

The files are kept on this device only, and only have to be provided once. A ZIP archive of the game folder is the quickest way to import them.
